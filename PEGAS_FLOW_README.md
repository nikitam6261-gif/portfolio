# PEGAS FLOW · LTL Control Tower

Новая версия операционного LTL-планировщика Пегас-Авто.

## Реализовано
- Control Tower с KPI и операционными alerts
- заявки клиентов с автоматическим созданием паллет
- единый реестр SSCC и Pallet Journey
- задания на забор и автоплан первой мили
- приемка и адресное размещение по температурным зонам
- Trip Builder с контролем веса, LDM и режима
- добавление/снятие паллет из рейса
- автосбор рейса
- транспорт, аналитика, поиск, сканирование и JSON export
- localStorage для интерактивной демо-работы
- адаптивный интерфейс

## Исходный прототип
Загруженный пользователем cold-chain LTL planner использован как функциональная референсная модель. Его логика (Заказчики, Паллеты, Сбор, Рейсы, Терминал, температурные режимы, вес и LDM) отражена в разделе Справка. В публичную ветку не переносились внутренние клиентские данные.
