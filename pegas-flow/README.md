# PEGAS FLOW

Рабочая версия LTL Control Tower для PEGAS-AUTO.

## Готовый серверный контур

- Supabase/PostgreSQL — единая операционная база для сайта и Telegram.
- Роли: `admin`, `director`, `dispatcher`, `warehouse`, `driver`, `manager`, `client`.
- Серверная RBAC-проверка и область данных по компании, клиенту и назначенному водителю.
- Сущности: заказчики, заявки, паллеты, задания на забор, транспорт, складские ячейки, рейсы, события, алерты и аудит.
- `pegas-flow-api` — основной API веб-интерфейса.
- `app-api` и `pegas-api` — compatibility proxy для старых версий интерфейса.
- `pegas-bot-api` — отдельный защищённый серверный API для Telegram: создание подтверждённых заявок, статус паллеты, отчёты и поиск заказчика.
- Прямой Data API закрыт для `anon`/`authenticated`; service-role key не попадает в браузер.

## Telegram `@pegas_flow_bot`

`telegram-webhook` v8 принимает обычный русский текст, голосовые сообщения и callback-кнопки.

Поддержано:

- `/start`, `/ping`, `/health`, `/me`, `/login`, `/help`, `/status`, `/summary`, `/report`;
- поиск паллеты по SSCC;
- операционные отчёты;
- создание заявки свободным текстом;
- сбор недостающих полей без выдумывания значений;
- черновик заявки с кнопками `Подтвердить / Исправить / Отмена`;
- запись заявки только после явного подтверждения пользователя;
- журнал входящих и исходящих Telegram-сообщений;
- отдельный журнал voice file id, длительности и transcript;
- журнал выполненных действий.

Таблицы Telegram-контура:

- `telegram_messages` — входящие/исходящие сообщения, voice metadata и transcript;
- `bot_drafts` — безопасные черновики действий до подтверждения.

## Голос и локальный AI

Каталог `local-ai/` содержит бесплатный локальный AI-мост:

- `faster-whisper` — распознавание русских голосовых сообщений;
- Ollama + Qwen — структурированный разбор свободного текста заявки;
- FastAPI — два локальных endpoint: `/transcribe` и `/parse/order`.

Архитектура:

`Telegram -> telegram-webhook -> Local Whisper/Qwen -> черновик -> подтверждение -> pegas-bot-api -> PostgreSQL`

LLM не имеет прямого права записи в БД. Он только превращает текст в структуру. Любое действие изменения данных выполняется серверным API только после проверки роли и подтверждения человеком.

Голосовой AI подключается через два Supabase Edge Function secrets:

- `PEGAS_LOCAL_AI_URL`
- `PEGAS_LOCAL_AI_TOKEN`

Инструкция и Windows-скрипты находятся в `pegas-flow/local-ai/`.

## Принцип данных

Фиктивные рабочие заявки, машины, рейсы, складские ячейки и паллеты намеренно не создаются. Операционный контур начинается с реальных данных пользователя. Исторические данные заказчиков сохранены отдельно как справочная аналитика.

Рабочая ветка: `agent/pegas-flow-production-v1`.
